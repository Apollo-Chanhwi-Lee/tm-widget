# TM — Token Monitor

> Claude · ChatGPT · Gemini 사용량을 실시간으로 보여주는 데스크탑 위젯

## 다운로드

👉 **[다운로드 페이지](https://apollo-chanhwi-lee.github.io/tm-widget)**

| OS | 파일 |
|---|---|
| macOS | `.dmg` |
| Windows | `.exe` |

## 기능
- Claude / ChatGPT / Gemini 탭별 사용량
- 현재 세션 % + 주간 % 실시간 표시
- 맨 위 고정 ON/OFF
- 5초마다 자동 갱신
- 트레이 숨김 / 완전 종료

## 개발

```bash
npm install
npm run dev       # 개발 서버
npm run build:mac # macOS .dmg 빌드
npm run build:win # Windows .exe 빌드
```
